Summary

In this experiment, I learned about two different ways of solving a problem in Python: iteration and recursion. In the iterative method, I used loops to repeat the required steps. In the recursive method, the function calls itself again and again until the base condition is reached. I also took input from the user and calculated the execution time of the programs. This helped me understand how the programs work and how time complexity is used to measure their performance.

Conclusion

From this experiment, I understood the basic difference between iteration and recursion. Iteration uses loops, whereas recursion uses a function that calls itself. I also learned how to find the time complexity and execution time of a program. Both methods can be useful depending on the problem, but iteration can be simpler for some problems while recursion makes some problems easier to understand and solve.
