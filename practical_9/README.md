Summary

In this experiment, we implemented Prim's Algorithm using Python to find the Minimum Spanning Tree (MST) of a weighted graph. The vertices, edges, and their weights were taken as user input. We also calculated the total cost of the MST and measured the execution time.

Conclusion

From this experiment, we learned how Prim's Algorithm can be used to connect all vertices of a graph with the minimum possible total weight. The algorithm selects suitable edges while avoiding unnecessary connections. This helped us understand the practical use of Minimum Spanning Trees in graphs.
