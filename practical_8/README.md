### Summary

In this experiment, we implemented a graph using Python and performed **DFS (Depth First Search)** and **BFS (Breadth First Search)**. The graph and starting vertex were taken as user input. We also measured the execution time of both algorithms and studied their time and space complexities. This helped us understand how DFS and BFS visit the vertices of a graph in different ways.

### Conclusion

From this experiment, we learned how to implement and traverse a graph using **DFS and BFS**. DFS explores one path deeply before backtracking, while BFS visits vertices level by level. Both algorithms have a time complexity of **O(V + E)**. This experiment helped us understand the practical use of graph traversal techniques.
