### Summary

In this experiment, we implemented **Kruskal’s Algorithm** in Python to find the **Minimum Spanning Tree (MST)** of a weighted graph. The algorithm sorts the edges based on their weights and selects the smallest edges while avoiding cycles. Finally, we calculated the total cost of the selected edges.

### Conclusion

From this experiment, we learned how Kruskal’s Algorithm can be used to connect all the vertices of a graph with **minimum total cost**. It helped us understand how edges are selected and how cycles are avoided while creating a Minimum Spanning Tree.
