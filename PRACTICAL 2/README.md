Summary:

In this experiment, I learned how Linear Search and Binary Search work using Python. Linear Search checks each element one by one until the required element is found, so it is easy to understand and works on both sorted and unsorted data. Binary Search is faster because it repeatedly divides the search space into two halves, but it only works when the data is sorted. I also learned how to take user input, calculate execution time, and understand the time and space complexity of both algorithms.

Conclusion:

From this experiment, I understood that both search algorithms have different uses. Linear Search is simple and suitable for small or unsorted lists, while Binary Search is more efficient for large sorted lists because it takes less time to find an element. By implementing both algorithms in Python, I gained a better understanding of searching techniques and when to use each algorithm.
